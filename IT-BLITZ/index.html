How to Play

  1. Set up 3 to 5 teams and give each a name.
  2. Teams take turns — the active team picks a category and point value.
  3. Answer before the 15-second timer runs out.
  4. Correct answers add the tile's points to that team's score.
  5. Wrong answers (or a timeout) subtract the tile's points — scores can go negative!
  6. Steal (if on): after a wrong answer, the next team gets one shot to steal the points — a missed steal costs them nothing.
  7. Each tile can only be played once, then the turn passes on.
  8. Play continues until all 30 questions are done.
  9. If the round timer runs out first, the game ends and the team with the highest points wins.
  10. Otherwise, the team with the highest score after all 30 questions wins the blitz!
  11. Tied for first? First team to grab the microphone answers a bonus question to break it.

Restart game?

This resets every team's score and clears the board. The same teams and settings are kept.

🌐 Interface Language

Switches the game's built-in buttons, labels and messages — verdicts, steal & tie-breaker prompts, How to Play, results. Your title, categories, questions and team names stay exactly as you typed them. This editor stays in English. Players can flip it anytime with the EN | TL button on the start screen and in the game header (that choice is remembered too).

How editing works

  • Changes are only used after you press ✔ Save (or Ctrl+S). Save checks that every question has text, 4 filled-in choices and exactly one correct answer, and that every timer and point value is a positive whole number.
  • Saved content is remembered in this browser (localStorage), so it survives a refresh. On another computer, use Export / Import.
  • Export saves content and settings in one file. Import loads it into the editor — review it, then press Save. A file without "settings" keeps your current settings; a file without "branding" (version 1–2) uses the default branding. Reset to Default brings back the original IT BLITZ content, settings and branding.

Question pack JSON format

{
  "format": "it-blitz-question-pack",
  "version": 3,
  "title": "IT BLITZ",
  "subtitle": "Information Technology Challenge",
  "tagline": "Pick a category. Choose your points. Test your IT knowledge.",
  "callToAction": "Are you ready to test your IT knowledge?",
  "categories": [                      // exactly 5 categories
    {
      "name": "Programming",
      "questions": [                   // 6 questions: 2,500 → 20,000
        {
          "points": 2500,
          "question": "What keyword is used to define a function in Python?",
          "choices": ["function", "def", "func", "define"],   // exactly 4 (A–D)
          "correct": "B"                                       // "A", "B", "C" or "D"
        }
        // … 5 more (5000, 7500, 10000, 15000, 20000)
      ]
    }
    // … 4 more categories
  ],
  "bonus": [                           // tie-breaker questions (optional, 1 or more)
    { "question": "How many bits are in one byte?", "choices": ["4","8","16","32"], "correct": "B" }
  ],
  "settings": {                        // optional — missing keys keep current values
    "questionTime": 15,                // seconds
    "stealTime": 10,                   // seconds
    "bonusTime": 20,                   // seconds
    "roundMinutes": 10,                // 0 = round timer off
    "penalty": "full",                 // "full" | "half" | "none"
    "stealOn": true,
    "bonusPoints": 10000,
    "targetScore": 0,                  // 0 = off
    "teamCount": 3,                    // 3, 4 or 5
    "teams": [ { "name": "Team Cyan", "color": "#25e0ff" }, … 5 in total ]
  },
  "branding": {                        // optional (version 3) — missing = defaults
    "schoolName": "Rizal National High School",
    "logo": "data:image/png;base64,iVBOR…",   // "" = no logo
    "accentColors": { "primary": "#25e0ff", "secondary": "#e23af0", "gold": "#ffd23f" },
    "language": "en"                   // "en" | "tl"
  }
}

Tips: "points" places each question on the right tile (if left out, the order 1–6 is used). "correct" may also be a number 0–3 (0 = A). If "bonus" is missing, the built-in bonus questions are used. The easiest way to start a new pack is to press Export and edit that file.
